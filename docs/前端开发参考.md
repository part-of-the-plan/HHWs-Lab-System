## 3. 路由与权限

### 路由定义 (`router/index.js`)

所有业务路由都是 `/` (Layout.vue) 的子路由。路由 `meta.perm` 定义所需权限码，`router.beforeEach` 做鉴权。

### 菜单结构 (menuMap)

```js
{
  home:    { title: '首页',         perm: null },
  device:  { title: '设备管理',     perm: 'device:list',  children: [
    { title: '设备列表', path: '/device/list',     perm: 'device:list' },
    { title: '设备分类', path: '/device/category', perm: 'category:manage' },
  ]},
  borrow:  { title: '借用管理',     perm: null,           children: [
    { title: '申请借用', path: '/borrow/apply',   perm: 'borrow:apply' },
    { title: '我的记录', path: '/borrow/my',      perm: 'record:self' },
    { title: '审批管理', path: '/borrow/approve', perm: 'borrow:approve' },
  ]},
  user:    { title: '用户管理',     perm: 'user:list',    children: [...] },
  security:{ title: '安全运维',     perm: 'log:view',     children: [...] },
}
```

### 三种角色权限

| 角色 | 权限码 |
|------|--------|
| SUPER_ADMIN | 全部 18 个权限 |
| LAB_ADMIN | device:* + category:manage + borrow:approve/return + record:all + stats:view |
| NORMAL_USER | device:list + borrow:apply + record:self |

## 4. 关键请求流程

### JWT 认证
- 登录后 token 存 `localStorage`，所有请求通过 `request.js` 拦截器自动带 `Authorization: Bearer <token>`
- 401 响应自动跳转登录页

### CSRF 防护
- 登录后调用 `GET /auth/csrf-token` 获取 token，存内存变量（不落盘）
- `request.js` 请求拦截器对 POST/PUT/DELETE/PATCH 自动带 `X-CSRF-Token` 头
- 收到 403 CSRF 错误时自动刷新 token 并重试一次（`_csrfRetried` 标记防死循环）
- 页面刷新后 `Layout.vue` 的 `onMounted` 调用 `initCsrfToken()` 重新获取

### API 基础路径
- 开发环境 (`.env.development`): `http://localhost:5000/api`
- 生产环境 (`.env.production`): `/api`（同源，Nginx 反代到后端）

## 5. 最近前端改动（重要：新对话需要知道）

### 5.1 消息角标（Layout.vue + 3 个 borrow 页面）

**实现方式**：Layout 用 `provide('refreshBadges', fetchBadges)` 注入刷新函数，子组件通过 `inject` 调用。

- **Layout.vue**：侧边栏菜单项显示红色数字角标
  - `/borrow/approve` 角标 = `pending + return_pending`（管理员看到的待办数）
  - `/borrow/my` 角标 = `my_overdue`（当前用户逾期数）
  - `onMounted` 启动 30 秒轮询兜底
- **BorrowApprove.vue**：审批通过/驳回/确认归还后调用 `refreshBadges()`
- **BorrowMy.vue**：申请归还后调用 `refreshBadges()`
- **BorrowApply.vue**：提交新申请后调用 `refreshBadges()`

**后端接口**：`GET /api/borrows/pending-count` → `{ pending, return_pending, my_overdue }`

### 5.2 首页看板点击跳转（Home.vue）

四张统计卡片可点击，跳转到对应筛选页：
| 卡片 | 跳转 |
|------|------|
| 设备总数 | `/device/list` |
| 空闲设备 | `/device/list?status=IDLE` |
| 借出中 | `/device/list?status=BORROWED` |
| 逾期未还 | `/borrow/approve?tab=OVERDUE` |

- 卡片 hover 上浮 + 阴影（`.stat-clickable` 样式）
- DeviceList.vue 的 `onMounted` 读取 `route.query.status` 预设筛选
- BorrowApprove.vue 的 `onMounted` 读取 `route.query.tab` 预设标签页

### 5.3 "我的记录"页面隔离（BorrowMy.vue + borrow.py）

- BorrowMy.vue 请求时带 `mine: 1` 参数
- 后端 `list_borrows` 遇到 `mine=1` 时强制只看本人，**即使有 `record:all` 权限也不看全员**
- 解决了"超管打开我的记录看到所有人"的混乱

### 5.4 审批管理新增"已逾期"标签（BorrowApprove.vue）

三个标签：`待审批 (PENDING)` | `待确认归还 (RETURN_PENDING)` | `已逾期 (OVERDUE)`
- OVERDUE 标签无常规操作按钮，但有 **"提醒归还"** 按钮
- 后端 `list_borrows` 支持 `status=OVERDUE` 动态过滤（BORROWED 且 expected_return_date < 今天）
- `POST /borrows/:id/remind` — 管理员提醒归还，记操作日志

### 5.5 逾期归还按钮修复（BorrowMy.vue）

`to_dict()` 返回的 `status` 是 `effective_status()`，逾期时值为 `"OVERDUE"` 而非 `"BORROWED"`。
- BorrowMy.vue 的"申请归还"按钮条件从 `row.status==='BORROWED'` 改为 `row.status==='BORROWED' || row.status==='OVERDUE'`
- 后端 `return_apply` 已兼容两种状态

### 5.6 修改密码弹窗（Layout.vue）

- 顶栏右侧"修改密码"按钮
- 弹窗：旧密码 + 新密码 + 确认密码，完整表单校验（8-20位/大小写/数字/特殊字符）
- 修改成功后自动退出登录，跳转登录页

### 5.7 时区修正（timezone.py）

- 所有 `to_dict()` 中的时间字段通过 `to_beijing_time()` 转换（UTC → UTC+8）
- 影响：BorrowRecord.to_dict() 的 apply_time/approve_time/actual_return_time/return_confirm_time，OperationLog.to_dict() 的 created_at

### 5.8 CSRF 中间件

- `__init__.py` 中 `check_csrf()` + `_path_traversal_check()` 作为 `before_request` 钩子
- **注意**：`__init__.py` 顶部必须 `from flask import Flask, request`，少写 `request` 会导致 NameError

## 6. Layout.vue 关键逻辑

### 侧边栏
- `sideMenus` computed：根据 `userStore.permissions` 过滤 `menuMap`
- `isCollapse`：侧边栏折叠/展开
- 角标通过 `badgeMap[child.path]` 显示

### 面包屑
- `PATH_MAP` 在 `<script setup>` 顶层立即执行，构建路径→标题映射
- `breadcrumbs` computed 根据当前 `route.path` 动态生成

### 修改密码
- `showPwdDialog` 控制弹窗
- `pwdForm` + `pwdRules` 表单校验
- 成功后 `userStore.logout()` + `router.push('/login')`

### 生命周期
- `onMounted`：`initCsrfToken()` + `fetchBadges()` + 30s 定时器
- `onUnmounted`：清除定时器

## 10. 注意事项

1. **Vue 模板自动转义** → XSS 天然防护，但后端仍对所有输入做 `sanitize_input()`（html.escape）
2. **Element Plus 中文语言包**需在 `main.js` 中配置
3. **开发环境** Vite 代理不启用（`.env.development` 中直接写 `localhost:5000`），生产用 Nginx 同源反代
4. **前端文件名**不要轻易改，router/index.js 中的懒加载路径需同步更新
5. **种子数据**用 `scripts/seed_test_data(1).py`（不要用不带 (1) 的老版本），借用记录现在有幂等去重
6. **CSRF Token** 存在内存中，页面刷新后 Layout.onMounted 自动重新获取
